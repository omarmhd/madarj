## القرار الأهم: الصوت بلا خادم

```ts
const { speak } = useSpeech();
speak('sheep', { rate: 0.8 });
```

**لا ملف صوتي واحد على الخادم.** المتصفح ينطق أي كلمة إنجليزية فوراً
عبر `SpeechSynthesis`. هذا ما يجعل منصة مجانية بألف مستخدم ممكنة.

وللنطق العكسي:

```ts
const { listen } = useRecognition();
const heard = await listen();   // ['three'] أو ['tree']
```

يقول الكلمة، والمتصفح يكتب ما سمعه. **تصحيح نطق آلي بصفر بنية تحتية.**

## اللعبة تتبع منهج الكتاب حرفياً

من §8.2 في الكتاب:

| قاعدة الكتاب | التنفيذ |
|---|---|
| المجموعات منفصلة، لا تُخلط | `groups` مجمّعة، والمجموعة تظهر في الرأس |
| الاستماع قبل الإنتاج | اللعبة استماع بحت، بلا نطق من المستخدم |
| الهدف 11 من 12 | `target = 11` وشاشة النتيجة تحكم عليه |
| الأزواج المتعثّرة تُدرَّب | تُعرض في النهاية مع أزرار استماع |
| سماع الاثنتين متتاليتين | زر مخصّص بعد كل إجابة — أهم لحظة تعليمية |

## الصرامة في `DayCard`

```tsx
if (!day.unlocked) {
  return <LockedDay />;   // 🔒 أكمل اليوم السابق أولاً
}
```

**والقفل ليس واجهة فقط.** الخادم يرفض أيضاً:

```php
if (! $this->isDayUnlocked($user, $weekNumber, $dayNumber)) {
    abort(403, 'هذا اليوم مقفل.');
}
```

فلا يمكن الالتفاف عليه بأدوات المطوّر.

### التحديث المتفائل

```tsx
setTasksDone(prev => ({ ...prev, [order]: next }));   // فوراً
await axios.post('/progress/task', {...});            // ثم الحفظ
// وعند الفشل: تراجع
```

السبب: المستخدم قد يغلق الصفحة في أي لحظة، ولا يجوز أن يفقد تقدّمه.

## الأمان في التمارين

```php
// Exercise.php
protected $hidden = ['answer', 'explanation'];
```

الإجابة **لا تصل المتصفح أبداً** قبل المحاولة. الواجهة ترسل، والخادم يحكم.

ومنهج الكتاب في الكشف:

```php
'reveal' => (! $isCorrect && $attemptNo >= 2)
    ? $exercise->answer['accepted'][0]
    : null,
```

الإجابة تُكشف بعد **محاولتين** لا فوراً — المحاولة الثانية هي التي تُرسّخ.

## التسجيلات محلياً

```ts
const localRef = await saveRecording(weekNumber, blob);  // IndexedDB
await axios.post('/recordings', {                        // الخادم
  week_number: weekNumber,
  duration_seconds: seconds,
  local_ref: localRef,     // ← مرجع فقط، لا ملف
});
```

الخادم يعرف: *"سجّل الأسبوع الأول، 118 ثانية"*. لا يملك الصوت.

## ما ينقص لتشغيل الأسبوع الأول

```bash
npm install dexie axios
npm install -D @types/dom-speech-recognition
```

وإضافة alias في `vite.config.ts`:

```ts
resolve: { alias: { '@': '/resources/js' } }
```
